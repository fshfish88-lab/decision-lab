# DECISION LAB V1 Brand Spec

- Brand name: `DECISION LAB`
- Chinese descriptor: `选择困难症终结器`
- Primary slogan: `今天，我们替你做决定。`
- Visual reference: `docs/decision-lab-v1-reference.png`
- Canonical V1 mark: `public/brand/decision-lab-mark.svg`
- Palette: `#F7F8FC`, `#FFFFFF`, `#14151A`, `#747782`, `#E9EAF0`, `#111527`
- Mode accents: random `#7268F2`, scientific `#D69C27`, mystic `#E87991`, AI preview `#72A95A`
- Typography: HarmonyOS Sans SC / system Chinese sans; Inter fallback for Latin and numerals
- Personality: serious interface, lightly absurd copy; never childish, cyberpunk, neon, or generic SaaS

The V1 mark is an original two-orbit decision symbol paired with the wordmark. It is not derived from another company logo.
