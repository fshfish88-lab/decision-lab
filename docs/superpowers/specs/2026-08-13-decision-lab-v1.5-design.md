# DECISION LAB V1.5 设计规格

日期：2026-08-13  
状态：已确认，待实施

## 1. 目标

在现有 V1.0 随机、科学、玄学决策闭环上完成 V1.5 前端版本：分享图片、历史记录升级、统计页面、成就系统、更多动画，以及可在后续接入真实服务端 API 的 AI 模式。

本版本必须在 AI API 尚未提供时仍可完整运行。随机、科学、玄学、历史、统计、分享和成就不得依赖 AI 服务。

## 2. 范围

### 2.1 本次实现

- 结果页生成 1080 × 1350 PNG 分享卡、下载图片和复制文字结果。
- 历史记录支持模式筛选、详情查看、删除、清空和复用原决策。
- 统计页面展示真实本地数据，包括本月决策次数、最常使用模式、反悔次数、决策服从率、模式分布和近期趋势。
- 结果页提供“我后悔了”，同一结果只计一次反悔。
- 成就按本地历史和行为数据自动计算、展示进度并在首次解锁时提示。
- AI 模式完成需求输入、接口状态、错误提示和后续流程所需的类型与服务边界。
- 增强结果揭晓、统计数字、历史详情和成就解锁动画。
- 桌面端与 375px 移动端响应式及无障碍复测。

### 2.2 本次不实现

- 真实 LLM 调用、API Key、Serverless Function 或后端部署。
- 登录、云同步、数据库、排行榜、朋友投票和社交平台直发。
- 用假 AI 回复冒充真实分析结果。
- 修改随机、科学、玄学模式已经验证的核心算法。

## 3. 实现路线

采用“完整 V1.5 前端 + 可替换 AI 接口层”。内部按以下顺序推进：

1. 扩展并迁移本地数据模型；
2. 完成历史、统计、反悔、分享和成就；
3. 完成 AI 模式前端流程和未配置状态；
4. 统一动画、响应式和回归验证。

这样可以让非 AI 功能立即可用，同时把未来 API 接入限制在服务层，不改动其余决策流程。

## 4. 数据模型与兼容

### 4.1 决策模式

`DecisionMode` 扩展为 `random | scientific | mystic | ai`。现有三种模式继续由本地确定性算法产生结果。AI 模式在 API 未配置时不会生成或保存伪结果。

### 4.2 本地存储

保留现有键 `decision-lab:history`，将存储载荷升级为版本 2。读取器同时接受 V1，并在内存中补全新增字段；下一次写入时保存为 V2。存储失败继续静默降级，不中断决策。

每条记录新增可选行为字段：

- `regrettedAt`：首次点击“我后悔了”的时间；
- `shareCount`：成功复制或下载的累计次数；
- `lastSharedAt`：最近一次分享时间。

独立使用数据键保存已展示的成就解锁提示，避免刷新后重复弹出。成就是由历史数据推导的结果，不把可伪造的“已完成次数”作为事实来源。

### 4.3 统计口径

- 本月决策次数：`createdAt` 位于当前自然月的记录数；
- 最常使用模式：全部历史记录中数量最高的模式，并列时显示“并列”；
- 反悔次数：存在 `regrettedAt` 的记录数；
- 决策服从率：`(总记录数 - 反悔记录数) / 总记录数 × 100%`，无记录时显示 `--`；
- 模式分布：各模式记录数及其占比；
- 近期趋势：最近 7 个自然日每天的决策次数。

问题文本不进行未经用户确认的类别推断，因此 V1.5 不展示“最常选择类别”。

## 5. 页面与组件

### 5.1 全局导航

- 主导航新增“统计分析”。
- 页脚版本更新为 V1.5。
- AI API 未配置时，顶部仍显示 `LOCAL MODE`，不制造在线状态。

### 5.2 首页和 AI 模式

AI 模式卡由禁用改为可选。选择后进入独立 AI 页面，避免把自然语言需求和普通选项编辑器混在同一表单。

AI 页面包含：

- 决策问题和 2–10 个候选项；
- 一段不超过合理长度的需求描述；
- 清楚的隐私说明和“AI 服务尚未接入”状态；
- 在服务未配置时禁用提交，并说明其他三种模式仍可使用；
- 为后续“提取约束 → 建议指标 → 用户修改 → 本地加权评分 → AI 解释”预留步骤结构。

前端不读取或保存 API Key。AI 服务通过单一 `AiDecisionClient` 接口访问；默认实现返回结构化的 `not_configured` 错误。未来只替换客户端实现或配置服务端端点。

### 5.3 结果页与分享

结果页新增：

- “我后悔了”：首次点击写入当前历史记录，之后显示已记录状态；
- “复制结果”：复制问题、模式、最终选择和简短解释；
- “生成分享卡”：使用浏览器 Canvas 绘制固定 1080 × 1350 PNG，并下载到本机。

分享卡使用项目现有色板和严肃实验室风格，包含品牌、问题、结果、模式、可信度、轻度荒诞文案和“结果仅供个人决策参考”。不加载远程字体和图片，避免 Canvas 跨域污染。下载或复制成功后才增加分享次数；失败时给出可读提示。

### 5.4 历史记录

- 保留现有筛选、删除和清空；
- 列表项可以展开或进入详情，显示问题、候选项、模式、结果、解释、时间、反悔与分享状态；
- 提供“再次使用”，把问题、候选项和模式带回决策流程；
- AI 记录只在未来真实 AI 流程成功后出现，当前不生成演示记录。

### 5.5 统计页面

使用 Bento 卡布局延续 Light Lab UI，不为了占位引入 Recharts。简单柱形、进度和趋势使用语义化 HTML/CSS 实现，并提供文字数值，使颜色不是唯一信息来源。

无记录时展示明确空状态和“开始一次决定”入口，不显示虚构样例数据。

### 5.6 成就系统

V1.5 包含以下成就：

- 初次见面：完成 1 次决策；
- 选择困难症患者：累计完成 10 次；
- 命运的奴隶：随机模式累计 20 次；
- 科学主义者：科学模式累计 10 次；
- 赛博算命师：玄学模式累计 10 次；
- 系统说什么就是什么：最近连续 5 次没有反悔。

统计页展示成就网格、已解锁状态和未完成进度。首次达到条件后显示一次轻量解锁提示；减少动态效果开启时取消位移动画。

## 6. 数据流

```text
本地决策完成
  → 保存/升级 History V2
  → 结果页展示
  → 用户可反悔、复制或下载
  → 更新对应历史行为字段
  → 统计函数重新从历史计算指标
  → 成就函数从同一历史推导状态
```

```text
AI 页面提交
  → AiDecisionClient
  → 当前：not_configured 结构化错误
  → 未来：Serverless API
  → AI 提取约束和建议指标
  → 用户确认/修改
  → 本地确定性加权算法决定排名
  → AI 仅生成解释
```

## 7. 错误与降级

- LocalStorage 不可用：决策仍可完成，历史、统计和成就显示本地存储不可用提示。
- 剪贴板不可用：复制失败并提示用户，不增加分享次数。
- Canvas 或下载失败：保留页面结果并显示重试提示。
- AI 未配置、超时、网络错误或返回格式异常：显示不同的友好错误；不保存 AI 结果，也不影响其他模式。
- 旧版或损坏历史数据：忽略无法验证的条目，保留其余有效记录；不让页面崩溃。

## 8. 动画与无障碍

- 常规过渡保持 150–600ms，结果揭晓不超过 3s；
- 统计数字只在进入视图时进行轻量递增；
- 成就解锁使用一次轻量缩放和淡入；
- `prefers-reduced-motion` 下取消数字递增、位移和缩放，仅保留即时状态变化；
- 所有新增按钮不小于 44px，保留键盘焦点、语义化标签和状态文字；
- 375px 下采用单栏，分享与结果操作不造成横向滚动。

## 9. 测试与验收

单元与组件测试覆盖：

- History V1 → V2 迁移、损坏数据与存储失败；
- 反悔幂等、分享计数和历史复用；
- 统计口径、空数据、并列模式和跨月/7 日边界；
- 六项成就的未解锁、进度与解锁条件；
- 分享卡文案模型和 Canvas 失败处理；
- AI 未配置、失败降级及其他模式不受影响；
- 新路由、导航、桌面端与移动端关键交互。

完成前实际运行：

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test:run
npm.cmd run build
```

并在真实浏览器检查桌面端和 375px：无页面级横向滚动、导航可用、控制台无错误或警告、核心流程无需刷新即可完成。

## 10. 完成定义

- 非 AI 的 V1.5 功能全部基于真实本地数据可用；
- AI 模式有完整入口、清晰边界和可替换接口，但不伪造结果；
- 原有三种模式与旧历史记录保持兼容；
- 所有规定检查通过，并留下桌面端和 375px 复测证据；
- API 到手后的工作只包括实现服务端端点和替换 `AiDecisionClient`，不重做 V1.5 页面结构。
