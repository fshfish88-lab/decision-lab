# 塔罗牌面插画与神秘解读增强设计

## 1. 目标

在不改变现有塔罗抽牌机制的前提下，增强玄学模式的视觉辨识度和叙事沉浸感：

- 22 张大阿卡纳分别拥有与牌义对应的象征性几何插画；
- 正位、逆位均提供三段简短的神秘叙事；
- 解读保持纯娱乐、含蓄和神秘，不输出具体行动建议或现实风险分析；
- Desktop 与 375px Mobile 保持清晰、克制且无页面级横向溢出。

## 2. 不变范围

以下机制不做修改：

- 每轮从 22 张大阿卡纳中展开 7 张不重复牌；
- 洗牌时预先确定牌、正逆位和候选项映射；
- 用户点击前不创建、不保存最终结果；
- 点击后不追加随机行为；
- LocalStorage 历史记录格式继续兼容旧数据；
- 不新增后端、AI 调用或外部图片依赖。

## 3. 视觉方向

### 3.1 风格

采用“组合式象征几何插画”：以统一的 SVG 线条系统组合太阳、月亮、星芒、冠冕、双柱、天平、轮盘、山峰、门扉等符号，为每张牌形成独立构图。

视觉约束：

- 延续现有奶油纸张、深墨色和细金色；
- 线条细而清楚，避免传统写实人物画；
- 允许少量实心色块，但不使用霓虹、复杂渐变和强烈发光；
- 牌面中央插画必须是视觉主体，罗马数字、牌名和正逆位信息仍清楚可读；
- 逆位继续通过整张牌面内容倒转表达，不另造一套图案。

## 4. 组件设计

新增 `TarotCardArtwork` 组件：

- 输入：`cardId` 和可选的尺寸/上下文样式；
- 输出：可缩放的内联 SVG；
- 通过 `cardId` 选择 22 个独立构图；
- 图案仅作装饰时使用 `aria-hidden="true"`，牌名仍由外层卡片提供可访问名称；
- 抽牌翻面卡和完整结果卡复用同一组件，避免两套图案漂移。

组件内部可抽取少量共享 SVG 基础件，例如 `Sun`, `Stars`, `Pillars`, `Orbit`，但不建立过度抽象的绘图框架。

现有 `TarotCard` 和 `MysticResult` 只替换中央占位图案，不改变按钮、翻面状态和结果布局的职责。

## 5. 解读数据设计

每张牌的正位与逆位在现有 `keywords`, `interpretation`, `strength` 基础上增加三项：

- `omen`：牌面征兆。描述此牌出现时的气息、象征和正在靠近的变化；
- `resonance`：命运映射。使用包含候选项占位符的模板，将牌义神秘地映射到本轮结果；
- `echo`：隐秘余韵。用模糊而有记忆点的短段落收束，不给出具体建议。

每段控制在约 35～70 个中文字符，总体维持三个短段落。文案风格要求：

- 像一份克制、严肃呈现的神秘档案；
- 允许使用“门、回声、轨道、影子、潮汐、星光”等意象；
- 不声称真实预测未来，不编造百分比指标；
- 不使用“你应该”“建议你”“风险是”等现实指导语气；
- 正逆位必须有明显不同的情绪和象征方向。

## 6. 数据流与展示

1. 牌阵引擎仍返回已预计算的牌、正逆位和候选项映射。
2. 用户点击牌背后，结果构建函数读取对应正逆位的三段解读数据。
3. `resonance` 模板中的候选项占位符替换为本轮被指向的选项名称。
4. 翻牌页显示关键词、现有单句牌意和一段精简神秘摘要，保持揭晓节奏。
5. 完整结果页显示三个独立短段落：牌面征兆、命运映射、隐秘余韵。
6. 历史记录保存渲染所需的新字段；旧记录缺少新字段时回退到原 `interpretation`，不显示空模块。

## 7. 响应式与动效

- 小卡牌中插画细节必须在约 116px 宽度下仍可辨认；过细的局部线条在小尺寸隐藏；
- 完整结果卡允许展示更完整的 SVG 细节；
- 插画随现有翻牌动画一起旋转，不新增持续闪烁或复杂粒子动画；
- 尊重 `prefers-reduced-motion`；
- 375px 下三个解读段落单列排列，牌面和文字不造成页面级横向滚动。

## 8. 兼容和异常处理

- 未识别的 `cardId` 使用通用星环图案，不导致结果页崩溃；
- 旧历史没有 `omen`, `resonance`, `echo` 时，使用旧 `interpretation` 作为单段回退；
- 候选项名称仍按现有 30 字符上限处理，动态插入后允许正常换行；
- 牌面在点击前继续不渲染正面文字和图案，避免辅助技术或 DOM 提前泄露结果。

## 9. 测试与验收

自动化验证：

- 22 张牌均能映射到独立的插画配置；
- 未知牌 ID 能渲染通用回退图案；
- 44 组正逆位含完整的 `omen`, `resonance`, `echo`；
- 命运映射正确插入当前结果选项；
- 点击前无正面牌名、图案或解读内容；
- 新结果显示三个神秘段落，且不出现具体建议型标题；
- 旧历史仍可渲染原单段解读；
- 现有 7 张牌、点击后保存和结果页流程测试继续通过。

浏览器验证：

- Desktop 检查 7 张牌、翻面和完整结果页的图案清晰度；
- 375px 检查卡组内部横向滚动、解读单列和页面无横向溢出；
- 检查浏览器控制台无错误或警告；
- 截图保存到根目录的 `过程文件文件夹/`，不放入成品工程。

## 10. 完成标准

- 22 张牌能凭主图案相互区分；
- 正逆位均提供三个神秘短段落；
- 解读不包含具体建议、现实风险分析或伪科学百分比；
- 抽牌算法、点击前隐私和历史保存时机保持不变；
- lint、typecheck、完整测试和生产构建通过；
- Desktop 与 375px 浏览器复测通过。
