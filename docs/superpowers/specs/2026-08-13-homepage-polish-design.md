# DECISION LAB 首页视觉精修设计

## 目标

在不增加新业务功能的前提下，把首页从“完成度较高的 V1”打磨成更紧凑、更有品牌记忆、更符合“严肃界面 + 不太严肃表达”的高频决策工具。

## 范围

1. 桌面 Hero 高度控制在约 400px，标题上限 64px，使常见 1080p 首屏能看到输入工作台上半部。
2. 决策终端每隔约 4 秒切换一张本地纸条；新结果不能与上一张相同，纸条完成收回与出票，机器轻微震动。
3. 随机、科学、玄学、AI 四张模式卡增加一行人格微文案。AI 仍保持禁用和 V1.5 标记。
4. 首页 CTA 根据模式显示“选择一种决策方式”“交给命运”“开始计算”“开始做法”；未满足输入条件时保持禁用。
5. 统一模式卡高度、排版、hover、selected、focus-visible 和禁用状态，并换成不依赖网络字体文件的稳定系统字体栈。

## 组件设计

- `DecisionMachine.tsx`：保存纸条文案、当前纸条和流水号；定时挑选不同于当前值的新纸条；使用 Framer Motion 完成轻量收纸、震动、出票。`useReducedMotion` 为减少动态效果用户关闭位移序列。
- `ModeCard.tsx`：新增 `aside` 属性作为第二层微文案，保持现有按钮语义与选择行为。
- `HomePage.tsx`：集中定义模式卡文案和 CTA 映射，继续复用现有 Decision Context，不改变决策流程和路由。
- `index.css`：只修改本轮涉及的 Hero、机器、模式卡、CTA 和字体规则，不重构其他页面。

## 交互与无障碍

- 动画只承担品牌表达，不阻挡输入；定时器卸载时清理。
- 纸条内容位于现有可读 DOM 中；机器保持单一无障碍标签，避免屏幕阅读器反复播报装饰性变化。
- 模式卡保留 `aria-pressed`；键盘焦点清晰，点击区域不低于 44px。
- `prefers-reduced-motion` 下不做震动和纸条位移，但可以更新静态文案。

## 验证标准

- 自动化测试验证 CTA 四种有效状态、模式微文案、AI 禁用，以及纸条不会连续重复并能定时更新。
- `lint`、`typecheck`、全部测试、Pages 构建检查均通过。
- 浏览器验证 Desktop 与 375px：无横向滚动，首屏比例改善，模式卡等高，CTA 文案正确，纸条动画可见。
- 重新推送 GitHub Pages，Actions 成功，线上首页和静态资源返回 200。

## 明确不做

- 不改 HashRouter。
- 不实现 AI、登录、后端、数据库或新决策模式。
- 不下载字体、图片、GIF、视频或 3D 模型。
- 不扩大到结果页、历史页之外的无关视觉重构。
