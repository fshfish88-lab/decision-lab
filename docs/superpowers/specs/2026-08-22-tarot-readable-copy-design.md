# DECISION LAB 可读塔罗文案结构设计

日期：2026-08-22

## 1. 核心目标

保留当前成熟的塔罗牌面与结果页布局，只调整文案结构和三个模块标题。玄学模式仍可使用娱乐性联想，但每一句都必须能被普通用户直接读懂，不再使用“回声穿过缝隙”“未被命名的符号”等抽象意象堆叠。

## 2. 固定信息顺序

每次塔罗结果统一按以下顺序表达：

1. 牌名与正逆位；
2. 三个关键词；
3. 牌面含义：解释这张牌本身代表什么；
4. 为什么是它：说明牌义为什么会映射到当前候选项；
5. 逆位提醒：提供一个风险、盲点或反面可能；
6. 一句 DECISION LAB 式冷幽默。

完整结果页的三个解读模块固定命名为“牌面含义 / 为什么是它 / 逆位提醒”。冷幽默作为第三个模块内独立的收束句显示，不新增大型 UI 模块。

## 3. 数据与兼容策略

- `interpretation`：改写为清楚、非建议式的牌面本义；
- `resonance`：保留 `{option}` 占位符，明确解释当前候选项与牌义的对应关系；
- `echo`：不再表示神秘余韵，改为风险或反面提醒；
- `punchline`：新增 DECISION LAB 冷幽默短句；
- `omen`：新结果不再依赖，持久化类型中继续作为可选旧字段保留，避免旧版 LocalStorage 读取失败。

旧历史缺少 `punchline` 时继续显示原单段 `interpretation`，不拼接不完整的新结构。

## 4. 文案规则

- 每段使用常用词，直接说明含义与因果；
- “为什么是它”必须出现当前候选项名称；
- “逆位提醒”无论抽到正位或逆位都显示，用于呈现该结果的反面可能；
- 不输出具体行动建议，不使用伪科学百分比；
- 禁止抽象套话，包括“命运缝隙、第三次回声、未被命名、最后一道光、轻响、余韵”等；
- 冷幽默保持克制、简短，不抢占结论。

## 5. 界面范围

- 保留现有牌面 SVG、卡片数量、网格、颜色和响应式布局；
- 翻牌摘要标题从“牌面征兆”改为“牌面含义”；
- 完整结果的三张卡片标题改为“牌面含义 / 为什么是它 / 逆位提醒”；
- 只为冷幽默增加一条轻量文字样式。

## 6. 验收标准

- 22 张牌、正逆位合计 44 套文案均包含三个关键词、牌面本义、候选项映射、反面提醒和冷幽默；
- 44 套新文案不包含禁用的抽象套话；
- 结果页按新标题展示，且候选项正确插入；
- 抽牌前仍不泄露牌面或解读；
- 旧版历史仍可读取；
- lint、typecheck、完整测试和 build 通过；
- Desktop 与 375px 均无横向溢出或控制台错误。
